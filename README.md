# Vizag Schools

Premium Expo + React Native + TypeScript mobile UI for discovering, comparing, and exploring schools in Visakhapatnam, Andhra Pradesh.

## What is included

- Splash, onboarding, login, signup, home, search, listing, detail, compare, favorites, profile, and admin screens
- React Navigation stack + custom bottom tab navigation
- React Native Paper component foundation
- Reusable UI components: `SchoolCard`, `SearchBar`, `CategoryChip`, `RatingBadge`, `FilterModal`, `SchoolGallery`, `CompareCard`, loading skeletons, and empty states
- Typed mock school data for Vizag discovery workflows
- Dark-mode-ready theme architecture
- Expo-ready app configuration

## Run locally

```bash
npm install
npm start
```

Then open the Expo QR code in Expo Go, or run:

```bash
npm run android
npm run ios
```
